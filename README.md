# Интерактивное резюме на HTML, CSS, JavaScript

Одностраничный сайт-резюме, сверстанный на чистом HTML, CSS и JavaScript без использования фреймворков. Вступительное
задание для школы Codemasters.

Опубликованный сайт: https://krealf.github.io/interactive-summary/

Референсы:
https://i.pinimg.com/736x/80/94/df/8094df73249f1497dd8eb6b8f9111e42.jpg

Обязательные задачи:

- [x] адаптивное одностраничное резюме;
- [x] интерактивный раздел навыков с категориями и поиском;
- [x] светлая и тёмная тема с сохранением выбранного варианта;
- [x] отдельный публичный GitHub-репозиторий;
- [ ] опубликованный через GitHub Pages сайт;
- [x] README.md с краткой информацией о работе.

Сведенья, которые должны быть на сайте:

- [x] имя и фамилию;
- [x] фотографию или аватар;
- [x] краткую информацию о себе;
- [x] образование;
- [x] навыки;
- [x] опыт работы, если он есть;
- [x] проекты, учебные работы или другие достижения;
- [x] контактную информацию.
- [x] чему вы учились;
- [x] какие учебные проекты выполняли;
- [x] какие технологии пробовали;
- [ ] какие курсы проходили;
- [ ] что изучаете сейчас.

Страничка должна:

- [x] аккуратно выглядеть;
- [x] нормально отображаться на компьютере;
- [x] нормально отображаться на мобильном устройстве;
- [x] не иметь горизонтальной прокрутки на небольшом экране;
- [x] иметь визуально различимые разделы;
- [x] использовать Flexbox и/или CSS Grid хотя бы для части расположения элементов.

С помощью JavaScript реализовать:

- [x] Разбить навыки по категориям и сделать функционал выбора навыков по категориям.
- [x] Сделать текстовое поле для поиска навыков. Причём список должен обновляться в реальном времени. Поиск не
  чувствителен к регистру.
- [x] Синхронизировать работу поиска и категорий.
- [x] В случае, если ничего не отображается, то выводить "Ничего не найдено".
- [x] Добавить переключение светлой и тёмной темы. Внешний вид должен переключаться без перезагрузки. После обновления
  тема должна сохраниться.
