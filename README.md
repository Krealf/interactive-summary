# Интерактивное резюме на HTML, CSS, JavaScript

Задача: сделать сайт-резюме для вступительного задания в Кодмастерс.

Обязательные задачи:
- [ ] адаптивное одностраничное резюме;
- [ ] интерактивный раздел навыков с категориями и поиском;
- [ ] светлая и тёмная тема с сохранением выбранного варианта;
- [ ] отдельный публичный GitHub-репозиторий;
- [ ] опубликованный через GitHub Pages сайт;
- [ ] README.md с краткой информацией о работе.

Сведенья, которые должны быть на сайте:
- [ ] имя и фамилию;
- [ ] фотографию или аватар;
- [ ] краткую информацию о себе;
- [ ] образование;
- [ ] навыки;
- [ ] опыт работы, если он есть;
- [ ] проекты, учебные работы или другие достижения;
- [ ] контактную информацию.
- [ ] чему вы учились;
- [ ] какие учебные проекты выполняли;
- [ ] какие технологии пробовали;
- [ ] какие курсы проходили;
- [ ] что изучаете сейчас.

Страничка должна:
- [ ] аккуратно выглядеть;
- [ ] нормально отображаться на компьютере;
- [ ] нормально отображаться на мобильном устройстве;
- [ ] не иметь горизонтальной прокрутки на небольшом экране;
- [ ] иметь визуально различимые разделы;
- [ ] использовать Flexbox и/или CSS Grid хотя бы для части расположения элементов.

С помощью JavaScript реализовать:
- [ ] Разбить навыки по категория и сделать функционал выбора навыков по категориям.
- [ ] Сделать текстовое поле для поиска навыков. Причём список должен обновляться в реальном времени. Поиск не чувствителен к регистру.
- [ ] Синхронизировать работу поиска и категорий.
- [ ] В случае, если ничего не отображается, то выводить "Ничего не найдено".
- [ ] Добавить переключение светлой и тёмной темы. Внешний вид должен переключаться без перезагрузки. После обновления тема должна сохраниться.

Допускается использовать:
- Библиотеки иконок
- Сторонние шрифты

Можно:
- Пользоваться документацией;
- Искать информацию через поисковые системы;
- Читать Stack Overflow и другие технические ресурсы;
- Смотреть примеры использования отдельных HTML, CSS и JavaScript API;
- Самостоятельно искать информацию о неизвестной технологии или возможности браузера;
- Использовать визуальные референсы для дизайна;
